# CHAPA — generador NFC

Compositor de tarjetas NFC para impresión (reseña Google, carta, redes y WhatsApp). Sube el logo, elige medidas y exporta PDF/PNG a 300 dpi.

## Cómo abrirlo

En la carpeta del proyecto:

```bash
node servidor.mjs
```

Luego entra a [http://localhost:8931/index.html](http://localhost:8931/index.html).

En Windows también puedes usar `servir-local.bat`. Para compartir un enlace temporal con otra persona, `compartir.bat`.

## Requisitos

- Node.js 18 o superior, o Python 3 (`python -m http.server 8931`)
- Navegador actual
